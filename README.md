# Nico World

Página de Nico World, vitrina de tres mundos para niñas y niños de 8 a 14 años: AstroWorld, FlagWorld y Humanity World. Paleta derivada de AstroWorld (azules y celestes) y la letra de las apps (Baloo 2, licencia SIL OFL en `fonts/`) en los títulos.

```
index.html     La página (HTML, CSS y JS en un solo archivo, sin dependencias ni CDN)
fonts/         Baloo 2
servidor/      Servidor de comentarios (Flask + SQLite) para PythonAnywhere
DOMINIO.md     Cómo conectar el dominio de GoDaddy con GitHub Pages
```

Sin cuentas, sin analítica, sin cookies, sin datos personales.
